# Laajennuksista yleisesti

Tutustutaan aluksi muutamaan yksinkertaiseen laajennukseen.
Laajennukset on luokiteltu "Laajennukset"-valikon alle
kategorioittain, jotta niiden löytäminen olisi helpompaa.
Esimerkiksi "Hahmonna"-alivalikosta löytyy erilaisia
työkaluja, jotka luovat annettujen tietojen mukaisia
objekteja. Parhaiten laajennuksiin tutustuu kokeilemalla niitä.
Käydään kuitenkin läpi muutamia laajennoksia esimerkkeinä.

## Viivakoodit

{: .figure-normal }
![Viivakoodit valikossa](../inkscape-laajennukset-valikko.png)

"Hahmonna" alivalikon alta löytyy alivalikko "Barcode / QR Code".
Täällä on kolme laajennusta, joilla voi tehdä tavallisia
klassisia viivakoodeja, datamatriiseja sekä QR-koodeja.

Kukin näistä laajennuksista avaa yksinkertaisen dialogi-ikkunan,
jossa kysytään luotavan koodin tyyppi sekä sisältö. Tyypillisesti
dialogissa on lisäksi "Live preview" -rasti, jolla saa esiin
esikatselun luotavasta objektista. Varsinainen objektin luonti
tapahtuu "Apply"-nappia painamalla.

{: .figure-normal }
![Viivakoodit valikossa](../inkscape-laajennukset-valikko.png)

Viivakoodiin syötetään valittuun standardiin sopiva numerosarja.

{: .figure-normal }
![Tavallinen viivakoodi](../inkscape-laajennukset-barcode_classic.png)

Datamatriisiin voidaan laittaa vähän enemmän dataa.

{: .figure-normal }
![Datamatriisi](../inkscape-laajennukset-datamatrix.png)

QR-koodeja käytetään tyypillisesti kuluttajamarkkinoilla ja
verkkosivujen osoitteita varten.

{: .figure-normal }
![QR-koodi](../inkscape-laajennukset-qr-code.png)


## Lorem ipsum

"Lorem Ipsum" -laajennus luo halutun määrän "pseudolatinaa",
eli paikanpitäjäksi tarkoitettua hölynpölytekstiä, jota käytetään
usein täyttämään tekstikenttä, jonka ulkoasua on tarkoitus
tarkastella ennen kuin tiedetään siihen tulevaa lopullista tekstiä.
