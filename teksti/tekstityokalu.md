# Tekstityökalu

{: .figure .figure-right }
![Tekstityökalun kuvake työkalupalkissa](../inkscape-teksti-ikoni.png)

*Tekstityökalulla* piirrokseen voi lisätä tekstejä joko irrallisina
teksteinä tai rivittyvinä tekstilaatikkoina. Tekstityökalun voi valita
työkalupalkista tai pikanappaimella *T*.

## Teksti

Irrallisen tekstin kirjoittaminen aloitetaan klikkaamalla haluttua kohtaa
piirtoalueella. Sen jälkeen kirjoitetaan teksti.

{: .figure-normal }
![Työkalulla kirjoitettu teksti Inkscape](../inkscape-teksti-esimerkki.png)

Kuten muillakin työkaluilla piirretyillä objekteilla, tekstille voi valita
täyttövärin, reunavärin ja reunaviivan paksuuden.

{: .figure-normal }
![Tekstin täyttö keltainen, reunaväri punainen](../inkscape-teksti-reuna_ja_taytto.png)

Tekstityökalussa on huomattavaa, että osa tekstistä on mahdollista valita
itse tekstityökalulla ja muuttaa valitun osan reunaviivan ja täytön väriä sekä reunan paksuutta.
Tätä voi käyttää esimerkiksi tekstin jonkin osan korostamiseen.

{: .figure-medium-row }
> ![Tekstin osa valittuna ja muutettu reunaväriä ja täyttöä](../inkscape-teksti-valitun_reuna_ja_taytto.png)
> ![Tekstin osasta reunaväri ja täyttö muutettu siniseksi ja vaaleanpunaiseksi](../inkscape-teksti-osan_reuna_ja_taytto.png)
> ![Sana Inkscape mustana tekstinä, jossa sc on punaisella](../inkscape-teksti-sc_punaisena.png)
> ![Tekstinä "Kettu juoksi yli järven". Sana "Kettu" korostettuna oranssilla.](../inkscape-teksti-Kettu_juoksi_yli_jarven.png)

Tekstityökalun asetuspalkissa on useita valintoja. Käydään ne läpi osissa.

![Tekstityökalun asetuspalkki](../inkscape-teksti-asetuspalkki.png)

### Kirjasinvalinnat

*Kirjasintyypin*, eli fontin, sekä sen ominaisuuksien valinta on ensimmäisenä tekstityökalun asetuspalkissa.

{: .figure-normal }
![Kirjasintyypin valinnat](../inkscape-teksti-fontit.png)

Kirjasintyypin valinta on pudotusvalikkona, joka näyttää sekä fontin nimen että esimerkin sen ulkoasusta.

{: .figure-normal }
![Kirjasintyypin valinnat](../inkscape-teksti-fontinvalinta.png)

Listassa näytetään kaikki tietokoneelle asennetut kirjasintyypit. Joskus tämä lista voi olla,
käyttöjärjestelmästä riippuen, myös uuvuttavan pitkä ja siellä saattaa toistua sama kirjasintyyppi
useampaan kertaan esimerkiksi eri kieliversioiden mukaan.

Seuraavana palkissa on kirjasimen tyyli, kirjasintyypistä riippuen tässä listassa voi olla vähän
tai paljon erilaisia tyylejä tavallisimmista **lihavoidusta** (bold) ja *kursivoidusta* (italic)
erilaisiin variaatioihin, kuten "thin", "condensed", "semo-bold", "ulta-bold" ja niin edelleen.

{: .figure-normal }
![Kirjasintyypin tyyli](../inkscape-teksti-fontin_tyyli.png)

Seuraavassa pudotusvalikossa on kirjasimen koko. Tekstinkokoa voi muuttaa joko tästä
tekstityökalulla taikka skaalaamalla koko tekstiobjektia valintatyökalulla.
Sopivin tapa riippuu yleensä tilanteesta.

Joskus voi olla myös tarpeellista valita kirjasinten koolle käytetty mittayksikkö.

{: .figure-normal }
![Kirjasintyypin mittayksikkö](../inkscape-teksti-fontin_mittayksikko.png)

Kuten värejä, myös lihavointeja, kursivointeja ja kokoa voi kohdentaa
joko koko tekstiobjektiin taikka vain valittuun osaan tekstistä.
Tekstiä voi myös rivittää rivinvaihdolla.

Pikanäppäin lihavoinnille on, kuten monessa muussakin ohjelmassa,
*Ctrl-B* ja kursivoinnille *Ctrl-I*.

{: .figure-normal }
![Tekstissä erilaisija muotoiluja](../inkscape-teksti-muotoiluja.png)

### Rivien asettelu

Asetuspalkin seuraavat valinnat liittyvät rivien asetteluun. Ensimmäisenä
on *rivivälien suuruus*. Oletuksena riviväli on "1,25 lines", eli
mitta yhden rivin yläreunasta seuraavan rivin yläreunaan on 1,25 rivin korkeutta.
Niiden väliin jää siis 0,25 rivin verran tyhjää tilaa.
(Jostain syystä tätä kirjoitettaessa käyttöliittymä näytti oletuksena arvoksi 0,00
vaikka väli todellisuudessa oli 1,25.)

{: .figure-normal }
![Tekstin rivien asettelun valinnat](../inkscape-teksti-asettelu.png)

Rivivälin suuruuden mittayksikköä on mahdollista vaihtaa. Vaihtoehtoina
on muun muassa printtimediassa käytetyt pt ja pc, fyysiset mittayksiköt
mm, cm ja tuuma sekä digitaalisessa julkaisemisessa usein käytetyt
px, em, ex ja %.

Asetuspalkin seuraavilla napeilla valitaan vivien haluttu sivusuuntainen
tasaus. *Vasemmalle*, *keskelle*, *oikealle* tai *molempiin reunoihin*.

{: .figure-small-row }
> ![Teksti tasattuna vasemmalle](../inkscape-teksti-tasaus_vasen.png)
> ![Teksti tasattuna keskelle](../inkscape-teksti-tasaus_keski.png)
> ![Teksti tasattuna oikealle](../inkscape-teksti-tasaus_oikea.png)
> ![Teksti tasattuna molempiin reunoihin](../inkscape-teksti-tasaus_molemmat.png)

**Huomaa: Molempiin reunoihin tasaamista on mahdollista käyttää vain tekstilaatikon kanssa. Ei "irrallisissa teksteissä".**

### Tekstin suunta

Seuraavat napit vaikuttavat *tekstin suuntaan* ja ovat oleellisia ennen kaikkea
erilaisten kirjoitusjärjestelmien kanssa toimittaessa.

{: .figure-normal }
![Napit tekstin suunnan valitsemiseen](../inkscape-teksti-tekstin_suunta_napit.png)

Ensimmäisenä "tavallinen" länsimainen vasemmalta oikealle ja riveittäin ylhäältä
alas etenevä teksti.

Sen jälkeen ylhäältä alas ja oikealta vasemmalle etenevä teksti. Käytännössä
tämä kääntää "normaalin" tekstin 90 astetta myötäpäivään.

Kolmantena ylhäältä alas ja vasemmalta oikealle etenevä teksti, jota saatetaan
tarvita joissain itämaisissa kirjoituksissa.

{: .figure-small-row }
> ![Teksti vasemmalta oikealle, ylhäältä alas](../inkscape-teksti-suunta-voya.png)
> ![Teksti ylhäältä alas, oikealta vasemmalle](../inkscape-teksti-suunta-yaov.png)
> ![Teksti ylhäältä alas, vasemmalta oikealle](../inkscape-teksti-suunta-yavo.png)


Seuraavat kolme valintaa määräävät kirjoitusmerkkien asennon. Automaattinen, pystyssä ja sivuttain.

{: .figure-normal }
![Teksti kirjoitettuna ylhäältä alas, vasemmalta oikealle, pystykirjaimin](../inkscape-teksti-pystyteksti.png)

Viimeiset kaksi kertovat kirjoitussuunnan joko vasemmalta oikealle (länsimaiset tekstit)
tai oikealta vasemmalle (esimerkiksi arabia).

### Kirjainasettelu

Viimeisenä oleva pudotusvalikko on kirjainmerkkien asettelun hienosäätöön.

{: .figure-normal }
![Pudotusvalikko kirjainten hienosäätöön](../inkscape-teksti-kerning.png)

Näillä lukuarvoilla voidaan säätää valitun tekstin osalta:
- kirjainvälin suuruutta
- sanavälin suuruutta
- kirjainten siirtoa omalta paikaltaan vaakasuunnassa (horizontal kerning)
- kirjainten siirtoa omalta paikaltaan pystysuunnassa (vertical kerning)
- kirjainten kiertoa

{: .figure-normal }
![Esimerkki tekstinkirjainten hienosäädöstä](../inkscape-teksti-hienosaato.png)

### Tekstin rivitys

Irrallista tekstiä voi rivittää lisäämällä tekstiin rivinvaihtoja.
Toinen vaihtoehto rivitykseen on tehdä se automaattisesti. Tämä tapahtuu
ottamalla kiinni tekstiobjektin oikeassa yläkulmassa olevasta kärjellään
olevan neliön muotoisesta kahvasta. Tätä kahvaa siirtämällä voi valita
rivin maksimipituuden. Tämän asetuksen säätämisen jälkeen rivit
rivittyvät automaattisesti sanavälien kohdilta.

{: .figure-normal }
![Tekstin automaattinen rivitys](../inkscape-teksti-rivitys.png)

## Tekstilaatikko

Toinen tapa lisätä piirrokseen tekstiä on *tekstilaatikko*.
Tekstilaatikon voi luoda piirtämällä suorakaiteen tekstityökalulla.
Tämä luo kirjoitettavalle tekstille kehyksen, jonka sisällä se sijaitsee
ja jonka ulkopuolelle se ei mene. Sivusuunnassa laatikko määrää
tekstin maksimileveyden, jonka jälkee se rivittyy. Pystysuunnassa
yli menevä teksti häviää näkyvistä.

Tekstilaatikon kokoa voi muuttaa tekstityökalulla raahaamalla
laatikon oikean alakulman kärjellään olevasta neliökahvasta.

Oikean yläkulman vaakasuorasta neliökahvasta laatikolle voi lisätä sen
sisään tyhjää tilaa. Näin tekstilaatikon voi asetella
suoraan muiden objektien kylkeen ja silti jättää tekstin ympärille tilaa.

{: .figure-medium-row }
> ![Tekstilaatikko](../inkscape-teksti-tekstilaatikko.png)
> ![Tekstilaatikko, johon lisätty tyhjää tilaa ympärille](../inkscape-teksti-tekstilaatikko-padding.png)
