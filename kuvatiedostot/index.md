# Kuvatiedostot

{: .figure-medium }
![](../../images/butterflies/monarch.svg)

Inkscapella pystytään käsittelemään useita eri tiedostotyyppejä.
Se pystyy käsittelemään ensisijaisesti vektorikuvia, mutta jonkin verran 
myös rasterikuvia.

Tiedostoja voi joko avata ja tallentaa taikka tuoda (import) ja viedä (export).
Näiden erona on se, että tiedoston avaaminen käsittelee avattavaa
tiedostoa kokonaan uutena dokumenttina, kun tuominen puolestaan tuo tiedoston
jo avoinna olevaan dokumenttiin uutena objektina.

Tallentaminen puolestaan tallentaa levylle nykyisen dokumentin kokonaisuudessaan
haluttuun tiedostomuotoon, kun taas vieminen tallentaa dokumentista
jonkin valitun osan erilliseen tiedostoon. Ehkä yleisin käyttötilanne
viennille on bittikarttamuotoisen png-kuvan luonti jostain dokumentin
osasta.
